# מונחים כלליים ומונחי התוכנית

מסמכי התוכנית קוראים למושגים מוכרים בשמות משלהם, וחלק מהשמות משווקים או מפשטים. המסמך הזה
ממפה כל מונח כללי לשם שהתוכנית נותנת לו, כדי ששאלה במילים הכלליות תיענה ממסמכי התוכנית.
הכללים עצמם — במסמכי התוכנית; הגדרות מונחי התוכנית — במילון המושגים. הערה מופיעה רק כשהשם
של התוכנית מסתיר משהו.

| מונח כללי | מונח התוכנית | הערה |
|---|---|---|
| צפיפות אנרגטית | "צפיפות קלורית" | |
| מאכלים משביעים לקלוריה — דלי צפיפות, עתירי סיבים או חלבון | "לפטיני", "מאכלים לפטיניים" | תואר שיווקי; אין קשר ללפטין שבמזון |
| ירקות לא־עמילניים | "ירקות מנקים" | שום דבר אינו "מנקה"; זו רשימת ירקות דלי־עמילן, ותפוח אדמה, בטטה, סלק, תירס וקטניות אינם בה |
| דגנים מלאים שלמים, לא טחונים | "פחמימה לפטינית" מדרג 2 | ארטישוק ירושלמי נכלל אף שאינו דגן |
| קמחים ופחמימות מעובדות | "מאכלים טחונים", "קמחים" | הקריטריון הוא הטחינה, לא הצמח: גם קמח מלא בחוץ בשלב הניקוי |
| מדד גליקמי / עומס גליקמי | "מדרג הפחמימות" | סולם סדר לפי מידת העיבוד, לא מדידה |
| שומנים מוספים | "שומנים מרוכזים", "מנת שומן" | שומן שמוסיפים למזון; השומן שבתוך הבשר, הדג והגבינה אינו נספר |
| עמידות ללפטין על רקע אינסולין גבוה כרוני | "אפקט החסימה" | |
| אכילה מוגבלת בזמן | "חלון אכילה" | התוכנית מבדילה מ"צום לסירוגין" |
| סדר אכילה — רצף המזונות בארוחה | "סדר אכילה לפטיני" | |
| שלב אלימינציה | "ניקוי לפטיני", "חופשה מתוכננת" | |
| הגדלת נפח המזון במים ובירקות | "הצפה לפטינית" | |
| יום חופשי / ארוחת חופש | "יום הפינוק", "ארוחת פינוק" | |
| רעב פיצוי אחרי הגבלה | "ריבאונד גרליני" | |
| פעילות יומיומית לא־מובנית (NEAT) | "פעולות שורפות שומן" | |
| אכילה מודעת | "ראש חטוב" | |
| פריטטה | "פשטידה", "חביתת ירק" | ביצים אפויות עם ירקות וגבינה, ללא קמח. מתכון לפריטטה הוא מתכוני הפשטידה וחביתת הירק שבדפי התכל'ס של שבועות 4 ו־6 ובחוברות המתכונים; מנת חלבון וירקות, והפחמימה הלפטינית לצידה או בתוכה (הפשטידה עם הקינואה) |
